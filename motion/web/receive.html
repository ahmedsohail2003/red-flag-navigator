Phone walking test: doctor's view

It measures walking speed over 10 m with the phone's motion sensors, and a drop beyond normal variation two weeks running raises the home-test flag; it is not an ALS test.

Starting the page. If this message stays, start the server (python run.py, or python motion/server.py) and open this page from the address it prints.

Walking speed is not in the app's test list yet, so this page added it for itself. The app's own views will show it after the merge (motion/MERGE.md).

This browser is not keeping data (storage is blocked), so saved results last only until you reload, and the app will not see them.

Connect the phone

Connecting to the server…

This page must be opened from the project's server. In the project folder run python run.py (or python motion/server.py), then open the laptop address it prints, followed by /motion/receive.html.

  1. Join the phone to the same Wi-Fi as this laptop.
  2. On the phone, type the address above in full, starting with https://. Accept the certificate warning once: the server made its own certificate, so the phone does not know it yet.
  3. Tap Start, then walk the 10 m at your usual pace.
