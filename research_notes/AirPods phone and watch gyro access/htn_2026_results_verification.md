## Missing or contradicted

- **Aircade cannot run on Windows.** It is a macOS app: Package.swift targets macOS 14 and iOS 16, and the README says it "Requires macOS 14+, Xcode / Swift 5.9+, compatible AirPods, and Node.js/MongoDB for the station". CMHeadphoneMotionManager exists only on Apple platforms. On the user's Windows 11 laptop, AirPods motion can only come from an iPhone, iPad or Mac app that forwards it over the network. The MRU "AIRCADE" does exactly this: a Swift sender on a Mac pushes CMHeadphoneMotionManager data over a local WebSocket to a browser. (https://github.com/apollo-ullah/Aircade/blob/main/README.md ; https://github.com/aj0khi/aircade-mru-hacks)
- **Holding the AirPod in the hand needs Automatic Ear Detection turned off.** The notes do not mention this, though it is central to how the team built it. Their docs say: "Turn off **Automatic Ear Detection**, hold the earbud in your calibrated grip, and click **Start AirPods**". VERIFICATION.md says "handheld input works with Automatic Ear Detection disabled". Apple says that with this setting on, taking a bud out of the ear sends a disconnect event. The team also calibrates from three captured poses, saved per earbud, and pauses the game clock after 250 ms without motion. (https://github.com/apollo-ullah/Aircade/blob/main/DEVELOPMENT.md ; https://developer.apple.com/videos/play/wwdc2023/10179/)
- **How the iPhone controller streams to the Mac** (the notes say only "pairs an AirPod with an iPhone"):
  - Motion: the iOS app uses CMMotionManager at 60 Hz (`deviceMotionUpdateInterval = 1.0 / 60`, reference frame `.xArbitraryZVertical`).
  - Discovery and transport: the Mac advertises the Bonjour service `_aircade._tcp`, and the phone connects over plain TCP (no TLS, TCP_NODELAY, peer-to-peer allowed).
  - Messages: JSON, each prefixed with a 4-byte big-endian length, at most 8192 bytes. The Mac polls and the phone answers each poll with one sample, so no backlog builds up.
  - Haptics: the phone uses UIImpactFeedbackGenerator.
  - Info.plist needs NSMotionUsageDescription, NSLocalNetworkUsageDescription and NSBonjourServices.

  The same design works for streaming phone motion to any laptop. (https://github.com/apollo-ullah/Aircade/blob/main/Sources/ControllerLink/ControllerLink.swift ; https://github.com/apollo-ullah/Aircade/blob/main/iOS/AircadeController/PhoneController.swift)
- **AirPods sample rate.** Apple publishes no rate for headphone motion. The team's evidence:
  - VERIFICATION.md (Sep 19, 2026) reports "approximately 50 Hz" from the left AirPod on a Mac.
  - My computation from the team's 18-second capture (docs/evidence/RecordedSensorCapture.json): 552 left-AirPod samples over 18.0 s, about 30.6 Hz on average, with sensor timestamps on a 20 ms grid (gaps of 20 to 100 ms, median 40 ms).
  - An earlier imported right-AirPod capture averages about 14 Hz.

  Rates vary, so measure them on the actual hardware. For comparison, Apple (WWDC23) gives a 100 Hz maximum for CMMotionManager. On Apple Watch during workouts, CMBatchedSensorManager delivers 800 Hz accelerometer and 200 Hz device motion in one-second batches. (https://github.com/apollo-ullah/Aircade/blob/main/VERIFICATION.md ; https://github.com/apollo-ullah/Aircade/blob/main/docs/evidence/RecordedSensorCapture.json ; https://developer.apple.com/videos/play/wwdc2023/10179/)
- **Parts of Aircade the notes leave out:**
  - The optional camera hand-position signal uses Apple Vision's `VNDetectHumanHandPoseRequest` on AVCapture frames (HandTracker.swift).
  - Besides Astra and Jev there is a third AI opponent: a trained tennis opponent hosted on Baseten (baseten/tennis-opponent, BasetenTennisOpponent.swift).
  - A local Node.js + MongoDB "station" holds the API keys, makes the model calls, keeps optional player profiles and serves the leaderboard page.
  - Players sign in by scanning their HTN badge QR code.
  - `gpt-6-astra` is a real OpenAI API model ID: OpenAI's developer docs page lists a 1,050,000-token context window and an Apr 30, 2026 knowledge cutoff. The code calls `POST /v1/responses` with strict JSON-schema output. (https://github.com/apollo-ullah/Aircade/blob/main/Sources/Aircade/HandTracker.swift ; https://github.com/apollo-ullah/Aircade/tree/main/baseten/tennis-opponent ; https://developers.openai.com/api/docs/models/gpt-6-astra)
- **What the sources say about Aircade's placing.** Official data says only "winner, OpenAI: API Prizes" and "not a finalist". The first-hand team claim is "top 30" overall and "top 3 in openai track". Only third-party LinkedIn snippets say "3rd". The final report should present Aircade as a sponsor-prize winner and say its place within the OpenAI prize was not published.
